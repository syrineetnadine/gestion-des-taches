
# Application Python de Gestion des Tâches

## Présentation du projet

Ce projet consiste à développer une application simple en Python
permettant de gérer les tâches quotidiennes depuis une interface console.

Le projet est réalisé dans le cadre du module :
Outils collaboratifs avec Git / GitHub – Licence 1, Semestre 1.

## Fonctionnalités

L'application propose les fonctionnalités suivantes :

1. Ajouter une tâche :
   - Saisir le titre d'une tâche.
   - Refuser les titres vides.
   - Ajouter la tâche à la liste.

2. Afficher les tâches :
   - Afficher toutes les tâches enregistrées.
   - Afficher un message si la liste est vide.

3. Rechercher une tâche :
   - Rechercher une tâche à partir d'un mot-clé.
   - Afficher les tâches dont le titre contient ce mot-clé.
   - La recherche ne distingue pas les majuscules et les minuscules.

4. Quitter :
   - Fermer proprement l'application.

## Installation et exécution

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier main.py.
3. Vérifier que Python est installé.
4. Cliquer sur le bouton Run Python File.
5. Utiliser le menu affiché dans la console.

## Utilisation

Le menu principal propose :

- 1 : Ajouter une tâche.
- 2 : Afficher les tâches.
- 3 : Rechercher une tâche.
- 0 : Quitter.
